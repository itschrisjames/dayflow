    Background reminders

    A web app can't wake itself on iOS, so an alert that arrives while DayFlow is closed has to be sent to it. That needs a small server — server/README.md in the DayFlow repo has the whole thing, about sixty lines, and it runs free on Render, Fly or a Raspberry Pi. Paste its address and public key here.

    Until this is filled in, reminders still work — they just only appear while DayFlow is open.

    Connecting your calendars

    Google

    DayFlow has no server and no shared account, so it signs in with a Google OAuth client ID that belongs to you. At console.cloud.google.com: create a project, enable the Google Calendar API, then under Credentials create an OAuth client ID of type Web application and add your DayFlow address to Authorised JavaScript origins. Paste the client ID below.

    Apple

    There is no Apple Calendar API for web apps, and iCloud's CalDAV server refuses browser requests outright. The Shortcuts app is the way in: build this once and DayFlow can ask it for today's events.
